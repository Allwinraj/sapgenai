Read it as a sentence: traffic hits an API gateway (1). The agent runtime interviews, builds the JSON graph, checkpoints the run, and routes models by cost and latency (2–2b). Ingestion OCRs documents; matching and decision read a knowledge graph; math stays in a sandbox (3). SAP APIs and any external OpenAPI sit behind the same policy, DLP and idempotency (4). The workbench will not promote if quality, latency or cost regress, and can roll back (5). Context is OCR + hybrid RAG + graph + memory (6). Assurance watches cost, latency and drift (7). Identity, RBAC, OPA, DLP and a sandbox wrap every call (8). Kubernetes, mesh, Postgres, graph DB, object store and Vault sit underneath (9).

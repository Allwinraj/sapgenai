Read it as a sentence: work arrives at a touchpoint (1). The orchestration interviews, types the answers, builds a JSON graph and runs it by levels (2). Five skills execute and hand one envelope to the next (3). A skill may write a file, read mail, or post a document — but only after a person clicks (4). The workbench is how the flow is designed (5), the context fabric is the evidence a decision cites (6), assurance is the per-run proof (7), review and release is the dashboard (8), and it all sits on FastAPI, Pydantic, React and files on disk (9).
